# NutriTrack Personal

Private, installable nutrition and body-tracking PWA.

## Free iPhone hosting with GitHub Pages

1. Create a new PUBLIC GitHub repository named `nutritrack`.
2. Upload every file/folder from this package to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose **main** and **/(root)**, then Save.
6. After GitHub finishes publishing, open the Pages URL in Safari on iPhone.
7. Tap **Share → Add to Home Screen → Add**.

The repository contains only the app source. Food logs, body measurements and profile data are not committed or uploaded by the app; they remain in browser storage on the device. Use Export Backup from Settings before clearing Safari data or moving phones.
